# kæl. Portfolio — editable version

Open index.html in a browser. No build step or dependencies.

## Customize
1. Put your actual project images in assets/ (JPG, PNG or WebP). Landscape images work best.
2. Open portfolio-config.js in VS Code or Notepad. Fill in your public email, LinkedIn URL and image paths in the matching order. Use the exact case of each filename. Empty or failed image paths retain the original artwork; empty contacts are hidden.
3. Save and refresh the page. The images also appear in project detail windows once loaded.

## Publish with GitHub Pages
Create a public repository called kkaell-os.github.io on your GitHub account (or use an existing one with that name). Upload the contents of this folder, including index.html, portfolio-config.js, assets/ and optionally .nojekyll, at the repository root. Commit to main. In Settings > Pages > Build and deployment select Deploy from a branch, main, / (root), then Save. The site will be available at https://kkaell-os.github.io/ after successful deployment. Do not commit private information.
